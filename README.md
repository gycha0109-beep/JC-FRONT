# JC-FRONT

Journee 초기 Route Social Network 프론트 복원본입니다.

## Stack

- React 19
- Vite 8
- Lucide React
- Vercel SPA deployment

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

현재 1차 목표는 2026-07-10 초기 Journee 메인 대시보드 시안의 화면 구조와 분위기를 복원하는 것입니다.

CI는 `main` push 및 pull request에서 production build를 검증합니다.
